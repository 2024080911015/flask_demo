# 🚀 组队大厅 (Team Hub) 核心功能清单

组队大厅是一个基于 **GNN (图神经网络)** 驱动的精准职能组队网络，专为高校学生打造的竞赛/科研匹配平台。经过多轮迭代，现已具备完善的推荐算法、硬核的业务逻辑与优雅的交互体验。

## 🧠 1. 算法与智能化推荐
* **GNN 动态匹配排序**：大厅首页默认采用“GNN 推荐流”模式。系统通过提取用户的特征向量（Embedding），结合社交网络拓扑结构，动态计算当前用户与各队伍的 **MATCH 匹配度**，并将最契合的队伍置顶推荐。
* **多维特征融合**：Match 分数综合了“用户技能属性（你是谁）”与“社交网络链路（你认识谁）”，实现了属性与社交圈的协同过滤。

## 🎯 2. 全局检索与精准分类
* **十二大学科门类全量接入**：内置国家标准十二大学科门类（工学、理学、经济学等）及全学科通用顶级赛事，支持前后端无缝级联筛选。
* **全局模糊检索引擎**：搜索框支持多维度穿透搜索，用户可通过输入**比赛名称**、**队长昵称**、**队伍名称**、**空缺岗位需求**（如“爬虫”、“算法”）秒级定位目标队伍。
* **过期项目自动软删除**：招募截止日期早于当天的项目，将自动从公共大厅的检索流中“隐身”，但保留在相关人员的“我的管理”面板中，确保数据连贯性与大厅新鲜度。

## ⚔️ 3. 商业级团队管理与防冲突机制
* **同比赛严格互斥原则**：同一用户在同一个比赛类别下，只能拥有一个成功入队的身份。申请和审批环节均加入了强校验，杜绝“占着茅坑不拉屎”的现象。
* **意向自动大清洗 (防骚扰)**：当某成员被一支队伍成功录用后，系统会在后台自动抹除该成员投递给**同比赛其他队伍**的“待审核”申请，避免队长查阅无效简历，也避免成员收到多余的婉拒通知。
* **智能岗位调剂系统**：当多名成员申请同一坑位且发生冲突时，系统会拦截队长的“同意”操作，并弹出最高层级 (`z-index: 999999`) 的调剂面板，允许队长将其安全分配至其他空缺岗位。
* **双向解约机制 (踢人与退出)**：
  * **队长踢出**：队长可在管理面板主动移出正式队员，实时释放岗位坑位。
  * **队员退出**：队员可主动退出已加入的队伍或撤销申请。

## ✉️ 4. 站内信与事件通知系统 (Message System)
完美复用系统内置的 Message 消息表，实现了组队全生命周期的双向短信/邮件通知：
* **录用通知**：“你已成功加入【比赛名】（队伍名）！”
* **婉拒通知**：“【比赛名】（队伍名）婉拒了你😭，再接再厉！”
* **进队提示(队长端)**：“某某某已加入你的队伍...”
* **离队警报(双向)**：无论是队长踢人还是队员主动离队，双方都会立刻收到解约通知。

## 🎨 5. 极致打磨的 UI/UX 交互体验
* **防挤压排版**：右上角导航采用固宽（`w-[68px]`）与 `whitespace-nowrap` 技术，实现了精致的高级感“二二分布”方块按钮。
* **卡片式动态表单**：发布招募时，支持动态增删“队伍坑位（Slots）”，细化到每个坑位的专业要求和技能描述。
* **沉浸式图层管理**：修复了多级模态框（Modal）的堆叠上下文冲突，确保错误提示、确认弹窗和个人名片展示的完美叠放。
* **异常兜底弹窗**：重写了全局网络请求的 Catch 模块，精准捕获并弹窗展示前端语法或后端脱机错误，极大提升排错效率。
